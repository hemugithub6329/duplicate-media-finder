DUPLICATE MEDIA FINDER - WINDOWS APP

START THE APP
1. Keep all files and folders from this ZIP together.
2. Double-click DuplicateMediaFinder.exe.
3. If the browser does not open, go to http://localhost:8501.
4. Choose a folder and click Scan folder.
5. Review the selections before confirming a move. Moved files go into a
   timestamped _duplicates_ folder; they are not intentionally deleted.

ANDROID PHONE
This is not an Android app or APK. The app runs on the Windows computer.
To view it on a phone on the same trusted Wi-Fi:
1. Double-click StartMobile.bat on this computer.
2. Open the computer's Wi-Fi address shown by the launcher in the phone's
   browser, for example http://192.168.1.25:8501.
3. If Windows asks, allow access on a private network only.
Keep this computer on while using the app. Do not share it on public Wi-Fi.

TROUBLESHOOTING
- Copy and extract the whole ZIP. Do not move only the EXE.
- If port 8501 is busy, close another copy of this app.
- The app is unsigned. If Windows Security warns, review Protection History.
  Do not disable antivirus protection.
